## 1. 레이아웃 / 컨셉

### 1.1 전체 컨셉
- **모바일 앱 스타일** 레이아웃
  - 하단 탭바(Bottom Tab) 기반 네비게이션
  - 카드형 리스트, 풀-투-리프레시 등 모바일 패턴 우선
- **모바일 퍼스트**로 정렬하는 게 자연스러움.

### 1.2 하단 탭 구성 (3 탭)

| 탭 | 역할 | 주요 콘텐츠 |
|---|---|---|
| 📋 **파티 리스트** | 당일 모집 중인 파티 목록 + 대시보드 | 상단: 오늘의 추천 · 잔소리 코치 멘트 / 하단: 카드형 파티 리스트 |
| 🗺️ **지도** | 식당 위치 시각화 | 지도 + 식당 아이콘(카테고리/만족도/대기도), 식당 클릭 시 상세, 태그 필터 |
| ⚙️ **설정** | 개인 설정 + 부가 진입점 | 프로필, 알림, 코치, 뱃지, 즐겨찾기, 히스토리, 혼밥 모드 |

- (※ 검토: 대시보드를 파티 리스트 탭 상단에 통합 [현재 안] vs 별도 탭)
- (※ 검토: 히스토리·뱃지를 설정 하위 [현재 안] vs 별도 탭으로 노출)

- **T3. 설정 탭** — §3.4

- **S6. 만족도 리스트** — §3.2.D (대시보드 더보기 진입 가능)
- **S7. 즐겨찾기 식당 목록** — §3.4 (설정에서 진입)

- **M1. 식당 평가 모달** (대기시간/태그형 평가) — §3.12

- **M3. 추천 메뉴 추가 모달** (메뉴명/가격 입력) — §3.12
- **M4. 메뉴판 이미지 업로드/뷰어** — §3.12
- **M5. 한줄 후기 모달** (파티 종료 후) — §3.12
- **M6. 영수증 메모 모달** (선택, D3) — §3.12
- **M7. 해시태그 입력/자동완성 입력기** — §3.10
- **M8. 정렬/필터 바텀시트** (파티 리스트·지도) — §3.2
- **M9. 파티 합류 확인 모달** (중복 참여 경고 포함) — §3.6
- **M10. 파티장 위임 모달** — §3.6
- **M11. 다시 뽑기 (대시보드 추천)** — §3.2
- **M12. 동명이인 보조 입력 (소속/팀)** — §3.1
- **M13. 사일런트 런치 프리셋 토글** (파티 생성 안) — §3.7

- **N1. 출발 임박 알림** (B4, 브라우저 푸시 + 인앱 배너)
- **N2. 모집 마감/정원 충족 알림**
- **N3. 정원 미달 자동 무산 알림** (C2)
- **N4. 랜덤 선정 결과 알림** (당첨/미당첨)
- **N5. 다른 혼밥러 알림** (혼밥 모드, §5.2)
- **N6. 빈 상태(empty state)**: 오늘 파티 0개, 히스토리 0개, 즐겨찾기 0개

## 3. 화면별 상세

### 3.1 로그인 (F1)
- 실명 입력 단일 필드 + 입장 버튼
- 동명이인 충돌 시 보조 입력 모달(M12): 소속/팀 등
- (※ 검토: 재방문 시 이름 자동기억 여부)

### 3.2 파티 리스트 탭 (T1)
**상단: 대시보드 영역 (요구사항 §1)**
- **3.2.A AI 잔소리 코치 멘트** (§5.3) — 한 줄, 닫기 가능
- **3.2.B 날씨 한 줄 멘트** (§3.4.3) — "비가 와요. 가까운 식당 어때요?"
- **3.2.C 오늘의 추천 카드** (§1.1) — 가로 스크롤 카드들
  - 카드 탭 → 파티 생성 플로우로 직진 (메뉴·식당 프리필)
  - 카드 우상단 🎲 → 다시 뽑기(M11)
- **3.2.D 만족도 TOP 리스트** (§1.2) — "이번 주 만족도 높은 식당" / 더보기 → S6

**하단: 파티 카드 리스트**
- **상단 필터 바 (sticky)**
  - **해시태그 칩 행** (가로 스크롤) — `#가성비` `#한식` `#매운맛주의` `#든든한한끼` 등
    - 칩 탭 → 해당 태그가 달린 식당의 파티만 필터링
    - 다중 선택 가능 (선택된 칩은 강조, 우측 X로 해제)
    - 좌측 고정: "전체" 칩 (필터 해제) / 우측 끝: "더보기" → M7 입력기로 태그 검색
  - **정렬 토글(M8)**: 출발 임박순 / 잔여 인원순 / 가격대순 / 카테고리 필터
- 카드 1장 = 파티 1개
- 카드 내용: 파티명 / 메뉴 / 출발시간 / 인원(현재/정원) / 가격대 / 규칙 마커(🤫 사일런트 등) / 파티장 뱃지
- 우하단 FAB(+) : 파티 생성(F2) 진입
- 빈 상태(N6): "오늘 모집 중인 파티가 없어요. 직접 만들어볼까요?"
- 태그 필터링 결과 0건 상태(N6 변형): "이 태그로 모집 중인 파티가 없어요. 직접 만들어볼까요?"

### 3.3 지도 탭 (T2)
- 지도 위에 식당 아이콘 표시
  - 변형: 카테고리(한/중/일/양 색상) · 대기도(테두리 색) · 만족도(별점 뱃지) · 예약필수(🔒)
- 식당 아이콘 클릭 → 하단 시트 또는 식당 상세(S1) 진입
- 상단: 검색바 + 해시태그 칩 (인기 태그 가로 스크롤)
- 우하단: 현재 위치 / 회사 위치 토글 버튼
- 식당 상세 내 "길찾기" 버튼 → 외부 지도 앱(네이버/카카오) 딥링크
- (※ 검토: 마커 클러스터링 임계치)

### 3.4 설정 탭 (T3)
- **프로필**
  - 실명, 소속(동명이인 보조)
  - 식이 제한 태그 (B2) — 채식 / 알러지 / 매운맛 X 등
  - 노쇼 카운터 (C1) — 본인만 보이는 카운트
- **개인 진입점**
  - 즐겨찾기 식당(S7)
  - 내 히스토리(S3)
  - 내 뱃지(S5)
- **모드**
  - 혼밥 매칭(F3) 진입
- **알림 / 토글**
  - 출발 임박 알림 ON/OFF (N1)
  - AI 잔소리 코치 ON/OFF (§5.3)
  - 혼밥 노출 범위 (식당만 / 식당+자리 / 비공개)
- **정보**
  - 지도 제공사 표시 (네이버/카카오 — 결정 후)
  - 캘린더 연동 (D2, 추후)

### 3.5 식당 상세 (S1)
- 상단: 식당명 / 주소 / ★ 즐겨찾기 토글 (B1) / 지도 미니뷰 + 길찾기 버튼
- 메타 정보: 카테고리1·2, 대기도, 예약필수 여부
- **해시태그 칩 영역** — 클릭 시 해당 태그 검색 결과(S8). 태그 추가 입력기(M7).
- **추천 메뉴 리스트** (§3.3 요구사항) — 메뉴명/가격, "+ 메뉴 추가" → M3
  - 각 메뉴 옆 별점/코멘트 진입 → M2
  - 메뉴판 이미지 슬라이드 → M4
- **식당 만족도** — 별점·태그형 평가 요약, "평가 남기기" → M1
- **여기서 파티 만들기** 버튼 → F2 (식당 프리필)

### 3.6 파티 상세 (S2)
- 상단: 파티명 / 출발시간 / 잔여 인원 / 가격대 / 규칙 마커
- 식당 정보 카드 (탭 시 S1)
- **공지 영역** (B3) — 파티장 한 줄 공지 ("11:55 1층 로비")
- 멤버 리스트 — 실명 + 뱃지(미식가/모험가/호스트왕 등 §5.4)
- **합류 버튼** → 합류 확인 모달(M9), 중복 참여면 경고
- 파티장 메뉴 (kebab)
  - 파티 수정 / 취소
  - **파티장 위임** (C4) → M10
  - 공지 작성
- 종료 후 영역: "한줄 후기 남기기"(M5), "영수증 메모"(M6)
- 추가 스케줄(커피숍/산책코스) 표시

### 3.7 파티 생성 플로우 (F2)
> 1화면 폼 + 접이식 섹션, 또는 다단계 스텝퍼. 결정 필요.

요구사항 §2.1 항목을 빠짐없이 입력:
1. **파티명**
2. **출발 시간** / **참여 제한 시간**
3. **모이는 장소**
4. **메뉴 / 식당 선정**
   - 직접 입력 / 해시태그 검색(M7) / 즐겨찾기에서 선택 / 추천에서 선택
   - 음식점 URL · 지도 표시 자동 연동
5. **평균 가격대** (슬라이더 또는 칸 선택)
6. **인원수 제한 모드**
   - 선착순 / (※ 무제한·랜덤은 요구사항 §2.3 미정)
7. **모임 인원 산정 방식**
   - 생성자 직접 입력 / 랜덤 모집 / 지정 인원 (2명 이상)
8. **파티 규칙**
   - 자유 텍스트
   - 프리셋 토글(M13): **사일런트 런치** 🤫 / 셀프코너 자율 등
9. **추가 스케줄** (옵션) — 커피숍 / 산책코스
10. 미리보기 → 생성

### 3.8 히스토리 (S3, S4)
- **S3 목록**: 종료된 파티 카드 (날짜·식당·멤버 썸네일)
  - **상단 필터 바 (sticky)**
    - **해시태그 칩 행** — 다녀온 식당에서 자주 쓰인 태그 우선 노출
    - 부가 필터: 식당별 / 카테고리별 / 멤버별 / 기간
  - 빈 상태(N6)
- **S4 상세**: 파티 정보 + 한줄 후기들 + 멤버
  - **"재파티 생성"** 버튼 (§3.1) → F2 (동일 조건 프리필)

### 3.9 혼밥 매칭 모드 (F3, §5.2)
- 진입: 설정 탭 → "혼밥 매칭" 또는 지도 탭 상단 토글
- **상태 토글**: "지금 혼밥 중" ON/OFF + 식당 선택
- 같은 식당에 다른 혼밥러가 있으면 알림 카드(N5)
  - 합석 의무 없음 명시
- 노출 범위 옵션 (식당만 / 식당+자리 / 비공개)
- (※ 검토: 자동 노출 vs 수동 토글 — 프라이버시)

### 3.10 해시태그 검색 (S8, M7)
- **M7 입력기** (파티 생성·식당 상세에서 띄움)
  - 자동완성: 기존 태그 풀에서 제안 (오타·난립 방지)
  - 인기 태그 칩 노출
  - 새 태그 생성 가능 (글자수 제한)
- **S8 검색 결과**
  - 검색바에 태그 입력 또는 식당 상세에서 태그 클릭 시 진입
  - 결과: 해당 태그가 달린 식당 카드 리스트
  - 결과에서 식당 클릭 → S1

### 3.11 내 뱃지 (S5, §5.4)
- 이번 달 진행률 / 보유 뱃지 리스트
  - 🍱 미식가 / 🗺️ 모험가 / 👑 호스트왕 / 👻 노쇼왕
- 본인만 노출 vs 공개 노출 설정 (특히 노쇼왕)
- 멤버 리스트(S6)·파티 카드(T1)에 같이 보이는 *작은 뱃지*는 별도 노출

### 3.12 모달 모음
| 모달 | 트리거 | 내용 |
|---|---|---|

## 4. 요구사항 ↔ 화면 매핑

> 각 요구사항이 어느 UI 표면에서 처리되는지 명시.

### 5.1 공통 컴포넌트 패턴
- **카드 리스트 상단 필터 바** (sticky)
  - 구성: 해시태그 칩 행(가로 스크롤) + 정렬/필터 진입(M8)
  - 적용 화면: **T1 파티 리스트**, **T2 지도(상단 칩)**, **S1 식당 상세(칩 영역)**, **S3 히스토리 목록**, **S6 만족도 리스트**, **S7 즐겨찾기 식당 목록**
  - 동작: 칩 다중 선택, "전체" 칩으로 해제, 끝에 "더보기"로 M7 호출
  - 예외: **S8 해시태그 검색 결과** — 진입 자체가 단일 태그 필터이므로 상단 칩은 *현재 필터 표시 + 추가 태그 칩*

## 6. 미정 / 검토 항목

- 대시보드 위치 — 현재 안: 파티 리스트 탭 상단 통합
- 히스토리·뱃지 진입 경로 — 현재 안: 설정 하위
- 지도 제공사(네이버 vs 카카오)에 따른 마커 커스터마이즈 가능 범위
- 다크모드 여부
- 빈 상태(empty state) — 화면별 메시지 톤
- 파티 생성을 1폼 vs 다단계 스텝퍼로 갈지
- 다시 뽑기(M11) 쿨다운/횟수 정책
- 모달 vs 풀스크린 시트 사용 기준 (모바일 UX)
- 노쇼왕·노쇼 카운터 공개 범위
- 혼밥 모드 자동 노출 vs 수동 토글
